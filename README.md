# 軟板與軟硬結合板製程互動教學

Flex & Rigid-Flex PCB manufacturing – a bilingual (繁中／English) interactive course.

靜態網頁，內容在 `web/`：

- `index.html`：首頁
- `flex.html`：軟性電路板（3L）製程
- `rigid-flex.html`：軟硬結合板（1+4+1）製程
- `animation.html`：剖面製程動畫（3L、1+4+1、2+3 非對稱）
- `plating.html`：Tenting（蓋孔法）vs Pattern Plating（圖形電鍍法）

本機預覽需用 HTTP 伺服器，例如 `npx serve web`。
